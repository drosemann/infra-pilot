## Regenerating

Use real browser captures for future updates. The historical mockup process is
not reproducible from this repository and is documented below for context.

### 1. Real browser captures (preferred)

Requires Node.js 22+ and a running stack:

```bash
cd services/management-panel
npm install
npx playwright install chromium
npm run dev &
node ../../scripts/capture-screenshots.mjs
```

The script navigates the local panel, seeds demo state where
possible, and overwrites this folder. Review diffs before
committing; mask secrets and personal data.

### 2. Historical mockups

Before 2026-09-28 the five PNGs were mockups generated by an external
tool that is not tracked in this repository. They were replaced by real
captures on that date (see capture log); the previous versions remain
in git history. Only `tour.gif` is still a mockup. Use
`scripts/capture-screenshots.mjs` for future updates and keep text
generic (`Acme Corp`, `shop-api`) while avoiding real hostnames.
